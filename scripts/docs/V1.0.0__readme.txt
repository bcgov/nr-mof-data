-------------------------------------------------------------------------------
2. UPDATE THE WASTE DATABASE OBJECTS
	   - Applies Package updates.
-------------------------------------------------------------------------------

2.1  From the repo root, move to the scripts directory

     cd scripts

2.2  Connect to the target database instance as the schema owner (THE).

     sqlplus the/<password>@<database-instance>

2.3  Setup env and start logging
    
     spool V101.0.0__output.log
     SET ECHO ON
     SET SQLBL ON
     SET TRIMSPOOL ON

2.4  Run DML scripts in the prescribed order

     @THE/V1.0.1__feedback_category_code_ins.sql
     @THE/V1.0.2__euser_feedback_upd.sql

2.5  Commmit/Rollback

     If no ORA- errors were generated, commit the transaction.  
     
     COMMIT;

     Otherwise rollback.

     ROLLBACK;

2.6  Stop logging

    SPOOL OFF

2.7  Exit sqlplus.

     exit
